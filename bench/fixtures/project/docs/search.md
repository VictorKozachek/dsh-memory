# Поиск по памяти

Поиск использует SQLite FTS5 и ранжирование `bm25`: отрицательный скор, меньше
значение — лучше совпадение. По умолчанию ищутся только `verified`-записи,
`stale` отсекается хранилищем; параметр `status: all` нужен для отладки.

Запрос санитизируется: пунктуация (`-`, `:`, кавычки, скобки) не должна
превращаться в операторы FTS5. Санитайзер разбивает запрос на слова и
оборачивает их в кавычки, поэтому `memory.search` не падает на строке вроде
`FTS5 - bm25` или `npm: install`.

`matchMode: all` требует все слова запроса (AND), `matchMode: any` — хотя бы
одно (OR). Обычный ход использует `any`: в естественном сообщении почти всегда
есть слова, которых нет в памяти, и строгий AND давал бы пустые ответы. Но
`any` подмешивает слабые совпадения по общим словам, поэтому инъекция
ограничена top-k и бюджетом, а бенчмарк отдельно проверяет релевантность
выдачи, а не только факт непустого результата.

Сниппет строится вокруг первого совпадения и обрезается до 300 символов
(`search.snippet_chars` в конфиге). Сниппет не содержит полного текста записи:
полный текст доступен только через `memory.get`-подобные инструменты или БД.

Фильтры: `kinds` ограничивает типы записей, `status` — статусы, TTL отсекает
просроченные `decision`/`fact`/`answer` при выборке. Результат содержит
`id`, `title`, `snippet`, `source_path`, `source_ref`, `status`, `confidence`
и `score`.

## Ограничения FTS5 в этой задаче

FTS5 не умеет семантику: он ищет слова, а не смысл. Поэтому запрос
санитизируется и переводится в OR-токены, а качество поиска измеряется
бенчмарком по релевантным источникам. Эмбеддинги — отдельная опция (016),
которая может добавить гибридный скор, но не обязательна для MVP.

Ранжирование bm25 учитывает частоту слова и длину документа: короткие чанки
могут выигрывать у длинных при прочих равных. Это нормально для сниппетов, но
на длинных документах полезно смотреть на несколько результатов, а не только
на первый.

Фильтр по `status` по умолчанию `verified`: черновики и устаревшие записи не
должны попадать в ответы. Для отладки и бенчмарка можно запросить `all`, но
это явный режим, а не дефолт.
