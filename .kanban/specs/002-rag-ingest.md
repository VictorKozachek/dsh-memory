# 002 — RAG при установке: лексический максимум и опциональные эмбеддинги

Статус: принята 2026-11-09. Основание: решение владельца проекта (§16
внутренней спецификации) и [`PLAN.md`](../../PLAN.md).

## Решение

1. Основной пакет `dsh-memory` не содержит сетевого кода и не требует ключей:
   дефолт — FTS5, локальная SQLite, автоиндексация в фоне, наблюдаемость через
   `dsh-memory doctor/status/index --dry-run`.
2. Качество поиска без векторов поднимаем лексическими средствами (задача 020),
   а не установкой векторной БД.
3. Эмбеддинги — отдельный опциональный пакет `dsh-memory-embeddings`
   (дизайн-спайк 021, реализация — 016 после него). В основном пакете нет ни
   провайдеров, ни ключей, ни сетевых вызовов.
4. Внешняя векторная БД не ставится: при включённых эмбеддингах векторы лежат
   в той же SQLite (`BLOB`), поиск — brute-force косинус; ANN (`sqlite-vec`) —
   только при доказанной необходимости.

## Критерии готовности

### 020 Лексический поиск без векторов

- FTS5-индекс переведён на trigram-токенайзер (или второй индекс рядом), поиск
  переживает опечатки и словоформы на кириллице; замер до/после на корпусе
  проекта;
- русский стеммер Snowball (чистый JS, без зависимостей) применяется при
  индексации и запросе; тест на словоформах («индексатор/индексатора/индексация»);
- расширение запроса синонимами из локального словаря (файл в репозитории),
  выключается конфигом;
- `verified` Q&A-записи ищутся отдельным каналом (точное совпадение заголовка),
  результат выше обычных сниппетов;
- бенчмарк 015 прогоняется на новой схеме, hit-rate и токены сравниваются с
  чистым `unicode61`.

### 021 Пакет эмбеддингов: дизайн-спайк

- дизайн-док: отдельный бандл `dsh-memory-embeddings`, точка монтирования,
  конфиг (`enabled`, `provider`, `base_url`, `model`, `api_key_env`), таблица
  `embeddings`, гибридный скор BM25 + косинус;
- границы доверия: в основном пакете нет сетевых вызовов (тест/ревью), весь
  egress — только в отдельном пакете; `DSH_MEMORY_NO_NETWORK=1` запрещает сеть;
- бэкенды: локальная модель (WASM/ONNX или Ollama) и OpenAI-совместимый API;
  ключ только из env, не пишется в БД/логи/карточки;
- сценарий включения: без ключа/`base_url` — ошибка и откат на FTS5; при
  включении `doctor` печатает предупреждение об отправке текста провайдеру;
- критерии приёмки для 016 и открытые вопросы (дефолтный провайдер, модель,
  порог brute-force → ANN).
