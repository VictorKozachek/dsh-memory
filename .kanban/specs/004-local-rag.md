# 004 — Локальный RAG по умолчанию

Статус: принята 2026-11-11. Основание: решение владельца проекта от 2026-11-11
(локальная модель + локальная база по умолчанию, облако — опция) и дизайн
пакета эмбеддингов [`docs/embeddings-design.md`](../../docs/embeddings-design.md).

## Решение

1. **Локальная модель эмбеддингов** — ONNX/WASM через `@xenova/transformers`,
   дефолт `Xenova/multilingual-e5-small` (мультиязычная, ~100 МБ в квантованном
   виде). Веса **скачиваются при первом использовании** в
   `~/.dsh/memory/models` и дальше работают офлайн. Загрузка — только с явным
   согласием (`allow_download: true`, предупреждение в лог/`doctor`).
2. **Включены по умолчанию**: при установке `@vkozachek/dsh-memory-embeddings`
   гибридный поиск (FTS5 + локальные векторы) работает без настройки.
3. **Векторы** — BLOB в той же SQLite, brute-force косинус (до ~20–50 тыс. чанков).
   Отдельная векторная БД не ставится.
4. **Облако — опция**: `openai-compatible` и `ollama` включаются конфигом,
   с предупреждением и `DSH_MEMORY_NO_NETWORK=1` как жёстким запретом egress.
5. **Fallback**: модель не скачана/нет сети/нет `@xenova` — поиск остаётся на
   FTS5, плагин и ход не падают.

## Критерии готовности

### 032 Локальная ONNX-модель по умолчанию

- конфиг: `enabled: true`, `provider: "local-onnx"`, `model:
  "Xenova/multilingual-e5-small"`, `model_path: ""`, `allow_download: true`,
  `cache_dir: "~/.dsh/memory/models"`;
- при первом использовании модель скачивается в кэш (прогресс в лог), повторный
  запуск работает **без сети** (проверить с заблокированным сетью);
- `allow_download: false` и отсутствие локальной модели → понятная ошибка/warn и
  fallback на FTS5, без падения профиля;
- `DSH_MEMORY_NO_NETWORK=1`: скачивание запрещено (FTS5), скачанная модель
  работает офлайн;
- кэш модели не попадает в npm-пакет; `@xenova/transformers` — optional
  dependency, отсутствие не ломает основной пакет;
- тесты с мок-загрузчиком: успешная загрузка, отказ сети, cached-путь, битый
  файл модели.

### 033 Первый запуск локального RAG

- при включённых эмбеддингах первый поиск/индексация досчитывает векторы для
  существующих записей (backfill), прогресс виден в логе;
- `doctor` показывает провайдера, модель, путь кэша, статус (скачана/нет),
  размерность и число векторов;
- предупреждение о первой загрузке (размер, источник) один раз, без спама;
- ошибка загрузки/эмбеддинга не ломает ход; повторная попытка по событию
  `entries-changed`;
- тесты на backfill, статус doctor, NO_NETWORK.

### 034 Локальный RAG по умолчанию: приёмка

- после установки основного пакета и пакета эмбеддингов гибридный поиск
  работает без настройки (проверить на чистом профиле);
- бенчмарк реального корпуса: FTS5 vs гибрид с локальной моделью — hit-rate,
  экономия токенов, p95 латентности, размер кэша; отчёт
  `docs/benchmark-local-rag.md`;
- цель: качество не ниже FTS5 (hit-rate), p95 инъекции ≤ 50 мс или зафиксировать
  измеренное значение и решение;
- облачные провайдеры остаются опцией, `NO_NETWORK` и предупреждения работают;
- README/PLAN обновлены: локальный RAG — дефолт, облако — опция.
