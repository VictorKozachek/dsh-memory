## Задача
Namespace и write-back ролей

Зависит от: 025. Спека: `.kanban/specs/003-phase5.md`, раздел 029.

Прототип 018 не реализует namespace/write-back; закрыть правила, иначе роли засорят общую память.

## Критерии готовности
- [ ] роль пишет в свой namespace (или общий — по конфигу) с провенансом `role:<name>`; поиск роли ограничен namespace
- [ ] write-back роли — только `draft` с `confidence ≤ 0.6`; `verified` — только через `memory.verify` с `verified_by` ревью/теста/человека
- [ ] конфликт namespace не смешивает записи; тест на изоляцию и на запрет verified
