## Задача
Полировка роутера: disabled-путь, таймеры, контракт адаптеров, калибровка порога

Зависит от: 017. Спека: `.kanban/specs/001-mvp.md`, раздел 017.

Полировка по замечаниям теста 017 (не блокеры): disabled-путь ограничен
таймаутом L3, unref-таймеры, семантика строки-ответа L2, неоткалиброванный порог,
интеграция с живым ходом не проверена.

## Критерии готовности
- [ ] при `router.enabled: false` таймаут L3 не применяется (или явно документирован как часть контракта); тест на долгий L3 при выключенном флаге
- [ ] таймеры таймаутов не `unref`, либо добавлен keepalive: висящий провайдер в standalone-процессе должен давать RouterTimeoutError, а не выход процесса
- [ ] контракт адаптера L2: строка `ANSWER` не должна приниматься как текст ответа без confidence; тест на адаптер, вернувший голый маркер
- [ ] порог `confidence_threshold` откалиброван по бенчмарку реального корпуса (или зафиксировано решение оставить 0.6 с обоснованием) и отражён в docs/router-design.md
- [ ] проверить интеграцию `routeTurn` с живым ходом (mock AgentLoop) при выключенном флаге — регресс основного поведения пакета
