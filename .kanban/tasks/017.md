  Возврат: два дефекта против дизайна/критериев 1–2. Проверено: npm test 213/213 на Node 25.1 и 24.21; конфиг/флаг по умолчанию выключен; route-метрики L2/L3, savings только L2, причины, тесты выбора слоя/NO_ANSWER/ошибки/таймаута/стриминга/пустого L3; дизайн-док покрывает точку входа, стриминг, отмену, таймауты и логирование.
  
  1) Отмена во время L2 не срабатывает promptly. callWithTimeout при внешнем abort только вызывает controller.abort(), но Promise.race ждёт только провайдера и таймер; если провайдер игнорирует signal, routeTurn висит до таймаута. Воспроизвёл: l2 = () => new Promise(() => {}), router.timeout_ms=100, AbortController.abort() через 10 мс → AbortError через ~102 мс (то есть по таймауту, а не по отмене). Дизайн §5 обещает отмену хода; нужен отдельный reject/abort-promise в гонке (и снятие listener), чтобы внешний abort сразу завершал вызов, не уходя в L3; тест: отмена во время L2 при провайдере, игнорирующем signal, завершает routeTurn < timeout и L3 не вызван.
  
  2) Порядок route-события и токенов L3 обратный дизайну. В routeTurn onEvent({type:'route',...}) отправляется после await callL3WithTimeout, а токены L3 эмитятся через onToken во время этого вызова; UI получает токены раньше route. Дизайн §4: route-события «отправляются до токенов L3». Нужно эмитить route до вызова L3 (для disabled/L2 unavailable/L2 fallback/L2 confident — до соответствующего вызова/возврата) и добавить тест порядка: route встречается раньше первого token для всех путей. Сейчас тест проверяет только содержимое/порядок токенов.
  
  Не блокирует, к сведению: disabled-путь вызывает L3 через callProvider без router.timeout_ms (это сохраняет текущее поведение, но расходится с таблицей §6 — стоит оговорить); прототип сознательно не подключён к apply/hook (design §2), поэтому «нет регрессии при выключенном флаге» проверяется только на routeTurn; docs/benchmark-real.md перегенерирован из-за README; package.json/docs — общие файлы, оркестратору подтвердить; routeTurn с невалидным/пустым query бросает TypeError, что для прототипа ок.
