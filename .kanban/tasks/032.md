## Критерии готовности
- [ ] конфиг: enabled true, provider local-onnx, model Xenova/multilingual-e5-small, model_path пусто, allow_download true, cache_dir ~/.dsh/memory/models
- [ ] первое использование качает модель в кэш (прогресс в лог), повторный запуск работает без сети (проверка с заблокированной сетью)

- [ ] DSH_MEMORY_NO_NETWORK=1 запрещает скачивание (FTS5), скачанная модель работает офлайн
- [ ] кэш модели не в npm-пакете; @xenova/transformers — optional dependency, отсутствие не ломает основной пакет
