## Задача
Инъекция top-k в контекст хода

Зависит от: 004. Спека: `.kanban/specs/001-mvp.md`, раздел 010.

## Критерии готовности
- [ ] на каждом ходе поиск по первым 200 символам последнего сообщения
- [ ] не более 3 записей и ≤ 600 токенов, формат `[memory] title — snippet (source, status)`
- [ ] нет попаданий — блок не добавляется, 0 токенов
- [ ] `DSH_MEMORY_INJECT=off` отключает инъекцию
- [ ] ошибка поиска не ломает ход; добавка к первому токену измерена и ≤ 50 мс
