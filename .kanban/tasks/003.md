## Критерии готовности
- [ ] CLI `dsh-memory index --workspace <path>` обходит `**/*.md` и исключает `.git`, `node_modules`, `dist`, `build`, `tmp`, `.cache`, `worktrees`

- [ ] инкрементальность по `sha256` + `mtime`: неизменённые файлы не переиндексируются
