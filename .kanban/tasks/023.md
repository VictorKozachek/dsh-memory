Полировка по замечаниям ревью/теста 016 (не блокеры): офлайн-бэкенд под

усиление trust-boundary теста и инкрементальный backfill.

## Критерии готовности
- [ ] local-onnx разрешён при `DSH_MEMORY_NO_NETWORK=1`, если `allowRemoteModels=false` и `model_path` локальный (дизайн §8 против текущего поведения «падает до загрузки»); тест на оба режима
- [ ] `doctor`/лог для local-onnx не печатают предупреждение об отправке текста провайдеру (офлайн-бэкенд), убрать двойной префикс «ВНИМАНИЕ: ВНИМАНИЕ:»; для openai/ollama предупреждение остаётся
- [ ] README основного пакета документирует, что `memory.search` стал async и есть `memory.searchSync` для CLI/бенчмарка
- [ ] trust-boundary тест сканирует `lib/**` рекурсивно, `bin/` и динамические `import(...)`/`require(...)`, а не только `lib/*.js`
- [ ] событие `memory/entries-changed` для backfill API/Ollama-каналов: новые записи получают векторы после первого поиска, а не только после перезагрузки
