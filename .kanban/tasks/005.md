## Критерии готовности
- [ ] вставка записи `draft` с `hash = sha256(kind|title|text)` и UNIQUE
- [ ] дубликат по `hash` повышает `confidence`, объединяет `sources`, возвращает `deduped: true`
- [ ] запись без источника допустима только как `draft` и `confidence < 0.5`
- [ ] возвращает `{ id, deduped, status }`; `verified` напрямую не пишется
