# Бенчмарк MVP dsh-memory

Сценарий: 20 повторяющихся вопросов по фикстурному мини-проекту
`bench/fixtures/project` (10 документов), память проиндексирована заранее.
«До» — полный текст источника ответа; «после» — инъекция L1 (top-k сниппетов,
бюджет 600 токенов) плюс источник, если релевантного попадания не было.
Попадание считается релевантным только при совпадении `source_path`.

(вопросы составлены под её документы), а не обещание таких цифр на реальном
корпусе проекта; проверка на реальном корпусе — отдельная задача 022.
